just a simple drawing tool that you can use when you're bored
## Features
- 6 brush types
- Color palette
- PNG export
- shapes
- fill bucket
- eyedropper
- text tool
- symmetry mode (mirror / quad)
- autosave (your drawing comes back when you reopen the page)

## Shortcuts
`P` pen · `B` brush · `M` marker · `C` chalk · `S` spray · `W` watercolor · `E` eraser · `F` fill · `I` eyedropper · `T` text · `X` symmetry · `[` `]` size · `Ctrl+Z` / `Ctrl+Y` undo / redo
